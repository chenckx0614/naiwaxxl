# 消消乐（Match-3）

纯前端三消小游戏，单文件 `index.html` + 图片/音频资源，无框架、无构建步骤，直接用浏览器打开即可游玩。

## 目录结构

```
index.html          游戏本体（HTML + CSS + JS 全部内联）
naiwa/
  1/                第一关的棋子素材（a~i.png，当前取 b/d/f/g/i 五种）
bgm/
  bgm.mp3           背景音乐（循环）
  combo1~5.mp3       消除成功音效（每次随机播放一个）
  end.mp3            通关结算音效
```

## 玩法

- **滑动**任意棋子往上下左右，与相邻棋子交换；能凑成三个及以上同类会消除，凑不成就自动弹回
- 也可以**点选**两个相邻棋子完成交换
- 在限定步数内收集完顶部目标即为过关，剩余步数越多星级越高
- 底部四个道具：🔨 敲掉单格、💥 炸 3×3、🔀 重排棋盘、🪄 加 5 步

## 换关卡素材

改 `index.html` 里的 `TYPES` 数组即可，每项一个 `{ key, img, color }`：

```js
const TYPES = [
  { key:'b', img:'naiwa/1/b.png', color:'#7ec3f5' },
  // ... 换成新关卡图片路径
];
```

棋盘棋子、顶部目标图标会自动跟随更新。

## 本地运行

直接双击 `index.html` 即可。若浏览器因本地文件协议限制音频播放，用本地服务器打开：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

> 注意：浏览器有自动播放策略，通常需要用户先点击页面后才会有声音，这是浏览器限制，非代码问题。
